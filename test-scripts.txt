
---------------------------------------------------------------------------------------------------
This file contains a list of test scripts written in pseudo-assembly language.
Each script is designed to test specific functionalities of a memory system.
This is for showcase purposes and may not be executable in a real environment.
To execute these tests, ram files already contain the binary code of the test scripts,
just uncomment the desired test in both the instruction memory and data memory ram files.
---------------------------------------------------------------------------------------------------
